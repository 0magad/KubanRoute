# 🌿 KubanRoute

**Генератор персонализированных туристических маршрутов по Краснодарскому краю**

KubanRoute за 2 минуты создаёт персональный маршрут — винодельни, фермы, горы и скрытые жемчужины региона. Не список мест, а сценарий поездки с атмосферой и логистикой.

## 🚀 Быстрый старт

### Frontend (Next.js)

```bash
cd frontend
npm install
npm run dev
```

Откройте http://localhost:3000

## 🛠️ Стек

- **Frontend**: Next.js 14, Tailwind CSS, Framer Motion
- **Backend**: FastAPI, Python 3.11 *(в разработке)*
- **LLM**: Ollama (локальная нейросеть)
- **Карты**: Яндекс.Карты JS API v3

## 📋 Функции

- 5-шаговый опрос для персонализации
- Генерация маршрута с LLM-нарративом
- Интерактивная карта с маркерами
- Таймлайн по дням с карточками мест
- Форма для локального бизнеса
- Адаптивный дизайн (десктоп + мобильный)
